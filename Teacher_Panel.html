Teacher password

This is the TEACHER_KEY you set in the Sheet's script. It is checked on the server and is never stored in any web page.

Open or schedule a quiz

Sessions

The opening and closing times control when students may start; the quiz time is how long each one has after starting. Closing a session stops new students from starting. A student who is already in the middle of a quiz can still finish it. Creating a session for a lecture and group that already has one replaces it, including its password.

Student lists

Add or replace the list for one group. Paste the names, one per line, or upload a CSV or TXT file (in Excel: Save As, CSV UTF-8). A file with two columns, Group then Name, can fill several groups at once. Saving a list replaces that group's previous list.
